## ⚙️ Конфигурация

Все сообщения, ключевые слова запросов, интерактивная кнопка, HEX-цвета, Action Bar и звуки настраиваются в [`config.yml`](https://github.com/firewolfik/Spec/blob/main/src/main/resources/config.yml).
Каждое сообщение можно настраивать как **одной строкой**, так и **списком строк (многострочные сообщения)**.

## ⭐ Возможности

- **Скрытое наблюдение за игроком**:
  - Модератор переходит в режим наблюдения, телепортируется к цели и защищен от игрового мира.
  - Сохранение исходной позиции, гейммода и состояния полета с возвратом обратно после `/spec`.
- **Два режима скрытия**:
  - `VANISH` — модератору выдаётся vanish через EssentialsX API (скрыт из таба и мира; fallback на скрытие Bukkit).
  - `SILENT` — модератор остаётся виден в табе как обычный игрок в режиме выживания (`SURVIVAL` гм0), без серого цвета и ухода в конец списка (работает через пакеты NMS на версиях 1.16.5 – 1.21.x).
- **Система запросов на спек из чата**:
  - При обнаружении ключевых слов в чате (`чит`, `софт`, `вх`, `спек` и др.) автоматически создаётся запрос на наблюдение.
  - Модераторам отправляется интерактивное сообщение с отдельной кликабельной кнопкой (`%button%`) с настраиваемым hover-текстом и командой.
  - Настраиваемый кулдаун на создание запросов и время их действия (`expire`).
- **Управление алертами**:
  - Команда `/spec alerts` позволяет включить или отключить получение оповещений о запросах.
  - Выбор модератора надёжно сохраняется в базе данных SQLite (`plugins/Spec/sessions.db`).
- **Гибкие права доступа**:
  - По умолчанию наблюдение доступно **только по активным запросам** из чата (или за текущей целью).
  - Игроки с правом `spec.any` могут наблюдать за абсолютно любыми игроками в любой момент.
- **Удобный TabCompleter**:
  - При вводе `/spec ` + Tab отображаются только доступные подкоманды (`alerts`, `reload`), не засоряя чат общим списком игроков.
  - При вводе первой буквы ника предлагаются подходящие игроки (для `spec.any` — все игроки, без него — только игроки с активным запросом и текущая цель).
- **Защита модератора**:
  - Блокировка любого урона, эффектов зелий, возгорания, траты сытости, агро мобов и отбрасывания.
- **SQLite хранилище сессий и настроек**:
  - Автоматическое восстановление состояния игроков после рестарта или вылета сервера.
- **Визуальные эффекты**:
  - Настраиваемый Action Bar и настраиваемые звуки действий с валидацией версий.
  - Поддержка градиентов и HEX-цветов формата `&#RRGGBB` и стандартных кодов `&`.

## 🔧 Команды и права

### Команды

| Команда | Описание | Право |
|---------|----------|-------|
| `/spec <игрок>` | Начать наблюдение (по запросу или за любым с правом `spec.any`) / телепортироваться к текущей цели | `spec.use` |
| `/spec` | Завершить наблюдение и вернуться на исходную позицию | `spec.use` |
| `/spec alerts` | Включить / выключить получение оповещений о запросах на слежку | `spec.use` |
| `/spec reload` | Перезагрузить конфигурацию и базу данных | `spec.reload` |

### Права доступа

| Право | Описание | По умолчанию |
|-------|----------|--------------|
| `spec.use` | Использование режима наблюдения и получение запросов | `op` |
| `spec.any` | Наблюдение за любым игроком напрямую без активного запроса | `op` |
| `spec.reload` | Перезагрузка конфигурации плагина | `op` |

> Для режима `VANISH` на сервере рекомендуется наличие плагина EssentialsX.

## 📦 Сборка и установка

### Сборка из исходников

1. **Для Paper 1.21.11 (Java 21)**:
   ```bash
   mvn clean package
   ```
   Собранный файл: `target/spec-1.21.11.jar`

2. **Для Spigot / Paper 1.16.5 (Java 8+)**:
   ```bash
   mvn clean package -Pmc-1.16.5
   ```
   Собранный файл: `target/spec-1.16.5.jar`

### Установка

1. Поместите соответствующий jar-файл (`spec-1.21.11.jar` или `spec-1.16.5.jar`) в папку `plugins` вашего сервера.
2. Перезапустите сервер или загрузите плагин с помощью plugman.
3. Настройте `plugins/Spec/config.yml` под ваши предпочтения.
